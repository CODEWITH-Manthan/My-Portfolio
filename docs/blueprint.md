# **App Name**: RetroForge Portfolio

## Core Features:

- Hero Section: Display a bold introduction with a system status indicator, highlighted tagline, and tech stack overview.
- Navbar: Implement a retro-style navbar with the developer's name as '.exe' and navigation links, including a highlighted 'Hire Me' button.
- About Section: Showcase a brief developer bio with key skills and availability status badges.
- Tech Stack Section: Present a grid layout highlighting the developer's tech stack with bordered boxes.
- Project Showcase: Dynamically render a collection of projects in the main content area.
- AI Resume Tool: Leverage generative AI to rewrite bullet-points in a CV to maximize relevance to a specific job description. The user will provide the job description and their CV. The AI will then act as a 'tool' and identify which items on the CV should be emphasized, de-emphasized, or discarded in order to make the CV appear most closely aligned to the requirements listed in the job description.
- CV download: Provide a convenient way to download the user's CV.

## Style Guidelines:

- Primary color: Neon green (#39FF14) for highlights and accents, representing the retro tech theme.
- Background color: Dark gray (#222222) to emulate a terminal interface. Very low saturation reflects this darkness.
- Accent color: Yellow (#FFFF00) for interactive elements and important text blocks. Approximately 30 degrees 'left' of the primary hue on the color wheel; desaturated and darkened to contrast strongly.
- Body font: 'Space Grotesk', sans-serif, for a tech-inspired feel and readability. Headline Font: 'Inter', sans-serif, to match 'Space Grotesk'.
- Brutalist web design aesthetics with sharp, rectangular elements and strong borders.
- Implement a dotted grid background resembling a design canvas.
- System UI elements such as status indicators (red/green dots) to enhance the retro tech feel.
- Incorporate a subtle blinking cursor animation in the hero section.
